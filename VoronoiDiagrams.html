Voronoi Diagrams

Left-click empty space to add a point. Left-click and drag an existing point to move it. Right-click an existing point to delete it.

Voronoi polygons are formed by taking a set of seed points, then dividing the plane into regions such that all points within a region are closer to that region's seed than to any other seed. This implementation makes use of Delaunay Triangulation to obtain the dual of the Voronoi diagram first, then connects the circumcenters of the triangles according to whether they share an edge.

Delaunay Triangulation:

The Delaunay triangulation of a set of points divides the space formed by their convex hull into a set of triangles such that each triangle's circumcircle contains none of the points, except for the three used to generate it on its circumference, and possibly others on the circumference. This implementation makes use of Bowyer's Algorithm:
  1. Draw a large triangle which contains all the points under consideration. In this particular case, since we're interested in the Voronoi diagram, the triangle is drawn large enough so that any point on the screen is closer to any other point on the screen than to any of the vertices on this triangle.
  2. For each point in the set, do the following:
    1. For each existing triangle, check if the point is contained within its circumcircle. If it is, remove the triangle.
    2. There is now a set of points reachable from the point under consideration without crossing any lines. For each adjacent pair of these points (as viewed from the point under consideration), create a triangle involving those two points and the point under consideration.
Once all points in the set have been considered, the above algorithm will have produced a Delaunay triangulation of the set of points.

Voronoi Diagram from the Delaunay Triangulation:

Once the Delaunay triangulation is obtained, it is relatively straightforward to obtain the Voronoi diagram. Each triangle's circumcenter is equidistant from the three vertices (seed points) and is at least as close to those three as it is to any of the other seed points, thus making it a vertex of the corresponding Voronoi polygon. For each point, travel around it in a clockwise or counterclockwise manner, adding the circumcenters of each triangle containing it to the polygon.
